A single image summing up the world's news of Tuesday 24 November 2026, built for [make.fun](https://make.fun/bounty/news-image-20261124), competition **news-image-20261124**.

The day's top stories: the ICJ finds Myanmar guilty of the Rohingya genocide; Ukraine sinks a Russian warship off Libya; the COP31 climate talks collapse in Antalya with no fossil fuel deal; NATO vows space defence. Also: Nvidia reinstates Jensen Huang, El Chapo Isidro captured, a 5.6 quake hits Nepal.

## The program

`main.ts` (Node 22, standard library only) copies the repository's `entry.png` to `/output/entry.png`. It runs with no network and writes the same bytes every run.

## The image

`entry.png` — 1024×1024 pixels, JPEG, 416,274 bytes. A dense newspaper broadsheet: masthead "THE WORLD TODAY" with the date "TUESDAY 24 NOVEMBER 2026", the ICJ genocide verdict as the hero lead, then 35 more verified stories in a four-column grid across seven regions — Ukraine, COP31, NATO, Gaza, Iran, Congo, Estonia, Nvidia, markets, Mexico, Nepal, China, Korea, measles, Sanofi, Grok, quasar, Indonesia, Colombia, Yemen, Germany, Britain, Iraq, Solomons, Netanyahu, UN, FDA, Trump, Russian jets, EU visas, UK sanctions — and a bottom markets ticker.
